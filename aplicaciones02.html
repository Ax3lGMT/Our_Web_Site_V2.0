    📱 Herramientas Digitales

    Aplicaciones para mejorar
    tu organización

    Existen diferentes herramientas digitales que pueden ayudarte a organizar tus tareas, planificar tus horarios y aprovechar mejor tu tiempo.

    Herramientas recomendadas

    Estas aplicaciones pueden ayudarte a mantener tus actividades organizadas.

    CALENDARIO
    📅

    Google Calendar

    Permite organizar eventos, clases, tareas y actividades mediante un calendario digital interactivo y sincronizado.

    Visitar aplicación →
    TAREAS
    ✅

    Todoist

    Permite crear listas de tareas detalladas, establecer fechas límites y organizar diferentes proyectos o asignaturas.

    Visitar aplicación →
    WORKSPACE
    📒

    Notion

    Puedes utilizarlo como plantilla o espacio de trabajo para organizar apuntes, tareas, proyectos y bases de datos.

    Visitar aplicación →
    ENFOQUE
    🌱

    Forest

    Ayuda a mantener períodos de concentración mediante la técnica Pomodoro mientras estudias para evitar distracciones.

    Visitar aplicación →
